5. Best-practice sources used

SourceHow it shaped this changeImplementation choice
SEC EDGAR APIs XBRL/companyfacts concepts need taxonomy and unit context before comparison. Keep facts and industry profiles as review candidates, not automatic scoring inputs.
MacKinlay event-study paper Historical events need explicit event timing and windows before interpretation. Profile status depends on replay-decision availability, not later outcome narrative.
Fed SR 11-7 model-risk guidance Research models need documentation, validation separation, and issue tracking. Profile layer documents assumptions and blockers; validation remains separate.
